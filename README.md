# 🎂 星空生日蛋糕 | Galaxy Birthday Cake

[中文](#中文说明) | [English](#english)

## 中文说明

基于 **Python + Pygame** 的交互式星空生日蛋糕动画，包含透明玻璃罩、银河分层蛋糕、闪烁星光、动态烛光和缤纷粒子效果。

### 安装与运行

需要 Python 3 和图形桌面环境。

```bash
python -m pip install -r requirements.txt
python birthday_cake.py
```

### 操作说明

| 操作 | 效果 |
| --- | --- |
| 移动鼠标 | 星光拖尾 |
| 点击鼠标 | 彩带和星光粒子爆炸 |
| 空格键 Space | 熄灭 / 重新点燃蜡烛 |
| B 键 | 蛋糕上方庆祝粒子 |
| Esc / 关闭窗口 | 退出 |

## English

An interactive galaxy-themed birthday cake made with **Python and Pygame**, featuring a glass dome, a layered galaxy cake, twinkling stars, flickering candlelight, sparkling trails, and colorful particle bursts.

### Install and run

Requires Python 3 and a graphical desktop environment.

```bash
python -m pip install -r requirements.txt
python birthday_cake.py
```

### Controls

| Input | Action |
| --- | --- |
| Move mouse | Sparkling star trail |
| Mouse click | Confetti and sparkle burst |
| Space | Blow out / relight candle |
| B | Celebration particles above the cake |
| Esc / Close window | Exit |
